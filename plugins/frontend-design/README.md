# Frontend Design

UI and UX work end to end — design an interface for code that has none yet, improve an existing one through competing proposals, or build distinctive, production-grade components from a brief without the generic AI aesthetic.

## What's included

### Skills
- `/mdv-code-design-ui-ux` — Derive what a product is for from its code and design its UI/UX: spec plus a clickable HTML prototype
- `/mdv-optimize-ui-ux` — Improve an existing screen or flow: 3 different proposals (desktop, tablet, mobile), then implement the chosen one
- `/mdv-frontend-design` — Build components, pages or applications from a brief with real visual quality

### Commands
- `/mdv-html-to-pdf` — Render an HTML file (such as a prototype or proposal) to PDF via headless Chrome

## Installation

```
/plugin marketplace add dvomar/claude-codeworks
/plugin install frontend-design@codeworks
```

## Usage

Pick the skill by what you start from:
```
/mdv-code-design-ui-ux                                # code with no usable UI yet
/mdv-optimize-ui-ux the dashboard is hard to scan     # an existing UI to improve
/mdv-frontend-design a pricing page with three tiers  # a brief with no codebase
```
